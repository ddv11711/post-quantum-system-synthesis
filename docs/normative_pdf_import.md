# Импорт PDF в разделе «Нормативная база»

На странице «Нормативная база» предусмотрена отдельная зона загрузки PDF.

- Нормативные документы по-прежнему читаются из `documents/normative/`.
- Импортированные документы записываются в `documents/imported/` и показываются отдельно.
- Загружать можно до 10 PDF за запрос, не более 20 МБ каждый.
- Файл должен иметь расширение `.pdf` и начинаться с сигнатуры `%PDF-`.
- При повторении имени файл сохраняется под уникальным именем; исходный документ не перезаписывается.
- Для загрузки требуется CSRF-токен; работают выбор файлов, перетаскивание и резервная отправка формы без JavaScript.
- Данные в `documents/imported/` исключены из Git. При переносе сервера эту папку нужно копировать отдельно.
- Добавлены тесты `tests/test_normative_pdf_import.py`.

Для локального запуска:

```powershell
python manage.py check
python -m pytest tests/test_normative_pdf_import.py -q
python -m pytest -q
python manage.py runserver 127.0.0.1:8011
```

Примечание: проверка заголовка PDF отсеивает произвольные файлы, но не заменяет антивирусную проверку. Если приложение будет доступно извне, следует ограничить доступ к загрузке авторизованными пользователями и настроить серверные лимиты тела запроса.
